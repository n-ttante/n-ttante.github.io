국내여행 스크래치 지도 (PWA)

[파일 구성]
index.html              앱 본체 (지도 데이터, 화면, 저장 기능이 모두 들어 있음)
manifest.webmanifest    앱 이름·아이콘·전체 화면 설정
sw.js                   오프라인 실행을 위한 서비스 워커
icons/                  앱 아이콘 (192, 512, 마스크용, 아이폰용, 파비콘)
_headers                Cloudflare Pages / Netlify용 캐시 설정 (GitHub Pages는 무시됨)
.nojekyll               GitHub Pages용 (그대로 두세요)

[올릴 때 주의]
1. 이 폴더 안의 파일들을 "폴더째가 아니라 파일 그대로" 사이트 맨 위(루트)에 올리세요.
   (index.html이 주소의 맨 앞에 와야 합니다)
2. 주소는 반드시 https:// 여야 설치됩니다. (GitHub Pages, Cloudflare Pages, Netlify는 자동 제공)
3. 이 앱 전용 주소를 쓰세요. 같은 주소 아래 다른 프로젝트를 같이 올리면 저장된 기록이 공유됩니다.

[설치 (사용자)]
- 아이폰: Safari로 링크 열기 → 공유 버튼 → "홈 화면에 추가"
- 갤럭시: Chrome/삼성 인터넷으로 링크 열기 → 메뉴 → "앱 설치"(또는 "홈 화면에 추가")
- 설치한 뒤에는 설치한 앱 아이콘으로만 사용하세요. (아이폰은 Safari와 설치한 앱의 저장소가 분리됩니다)

[업데이트]
- 파일을 새로 올리면, 사용자가 앱을 열 때 뒤에서 새 버전을 받고 다음 실행부터 적용됩니다. 기록은 유지됩니다.
- icons나 파일 목록(sw.js의 SHELL)을 바꿨을 때만 sw.js의 CACHE 이름(ks-v1)을 ks-v2처럼 올리세요.
